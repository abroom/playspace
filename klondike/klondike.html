Klondike

The classic solitaire — clear the deck onto four foundations, ace to king.

How to play

  • Draw 1 or Draw 3 cards from the stock into the waste — only the top waste card is playable.
  • Build tableau columns down in alternating colors. An empty column only accepts a King (or a run starting with one).
  • Build foundations up by suit, Ace to King.
  • Click a card to pick it up (or the whole run above it, if it's a valid alternating sequence), then click a destination pile. Click the same card again to put it back down.
  • When the stock runs out, click it to flip the waste back over and keep going — there's no limit on redeals.
  • Undo any move, any number of times — each one is tallied. Give up any time to see how you did; either way, the final screen shows cards remaining and undos used.
  • Keyboard: U undoes. Escape puts down a held card, or opens the New game menu if nothing's held (or closes whatever's open). Backspace or B goes back to the Playspace index.
